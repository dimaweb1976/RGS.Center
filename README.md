# RGS.Center

## 1. Суть и назначение
Коротко (2-3 предложения): какую задачу решает проект и кто его пользователи.
приложение, которое будет запущено сервисом на внутреннем компьютере роботизированного гамма-спектрометра.

Java, Spring-app, for:
1. polling device states and control parameter values
2. keeping warehouse of status data&values of complex
3. managing long-term process
4. implementation of authentification
5. web-interface for data

Пользователи - те, кто будет пользоваться роботом:
* оператор комплекса-спектрометра - тот, кто привезёт образцы для анализа, загрузит в "аквариум", соединиться с ЭТОЙ программой через web-interface и запустит автоматизированный процесс на все 50 бутылок. Возможно ЕМУ дадим РУЧНОЕ управление. Также оператор имеет возможность посмотреть историю ранее проведённых измерений.
* сервисный инженер - тот, кто приехав починить должен получать ПОДРОБНЫЕ статусы всех модулей, журналы и прочее.
* возможно будет выделена роль администратора - того кто заводит учётные записи операторов и инженера.
